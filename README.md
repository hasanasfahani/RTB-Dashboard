# RTB Business Intelligence Dashboard — Demonstration Build

**Every figure in this application is synthetic.** The numbers are generated to show
the structure and capability of the proposed reporting layer, and they do not represent
RTB's actual financial position. Nothing here is drawn from RTB systems, and no real
data was used at any point.

A frontend-only demonstration of the RTB Business Intelligence Dashboard. It renders all
163 insights from the insights catalogue across four analytical layers and 30 sections,
using a coherent fixture for a mid-sized Iraqi private bank as at 31 August 2026.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

There is nothing else to set up: no backend, no API, no database, no authentication, no
environment variables. The application **runs fully offline** — it makes no network
request of any kind at runtime, not for data, fonts or images, because the demo may be
given on a bank guest network or none at all.

## What is in it

| Route | What it shows |
|---|---|
| `/` | Cover — scope and entry points |
| `/executive` | Executive 360° — headline band, attention strip, 8 insights |
| `/bank-wide` | 52 insights across 9 sections |
| `/retail` | 54 insights across 7 sections |
| `/corporate` | 49 insights across 7 sections |
| `/reports` | Your own reports — build a page from any of the 163 |
| `/reports/:id` | One report |
| `/insight/:id` | A single insight full-screen |
| `/dev/gallery` | Development surface: every chart component and variant |

Any section is deep-linkable — `/retail/deposits-liabilities` opens Retail with that tab
active.

**Keyboard:** `⌘K` (or `Ctrl+K`) opens a search over all 163 insights by id or title.
`Esc` closes it.

**Filters** in the top bar — period, branch, division, currency — apply to every chart
on every screen and persist as you move between pages. Clicking a branch on a map sets
the branch filter.

## How the numbers work

Everything derives from one fixture in `src/data/bank.ts` describing the shape of the
bank, so figures reconcile across screens: deposits by product, branch, currency and
segment each sum to total customer deposits; loans by product, sector and branch each
sum to gross loans; and the loan-to-deposit ratio shown anywhere is gross loans over
customer deposits. Those rules are assertions that run when the module loads, so a
build that starts is a build whose balance sheet adds up.

Series are generated by a seeded pseudo-random generator keyed on the insight id, so a
chart looks identical on every reload and never reshuffles mid-demonstration.

## Verifying it

```bash
npm run verify
```

Runs 353 checks across four suites: the catalogue and fixture (`verify:data`), all 236
chart panels (`verify:series`), the design-system and structural rules (`verify:tokens`),
and custom reports (`verify:reports`). `npm run build` type-checks and bundles.

## Scope

This is a demonstration, not a product. There is no backend, no persistence, no user
accounts and no export beyond the browser's own print. State resets on refresh,
deliberately, so a demonstration always starts from a known position.
